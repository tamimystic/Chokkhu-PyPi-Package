**Minimalistic Code. Maximum Output. Zero Heavy Dependencies.**

Chokkhu is a high-performance Python toolkit designed to streamline the complete Machine Learning lifecycle. From raw data loading to exploratory data analysis, cleaning, preprocessing, feature transformation, model training (from scratch), and evaluation. All functionalities are accessible via a unified, one-line API structure.

---

## Architecture Overview

Chokkhu is built on a functional API design consisting of 8 core pillars. Each pillar is designed to accept highly customizable parameters while maintaining a minimalist front-end interface.

1. ck.load() - Universal Data Loader
2. ck.eda() - Automated Exploratory Data Analysis
3. ck.clean() - Data Sanitation and Imputation
4. ck.preprocess() - Scaling and Encoding
5. ck.transform() - Dimensionality Reduction and Augmentation
6. ck.split() - Data Partitioning
7. ck.train() - Machine Learning Algorithm Execution
8. ck.evaluate() - Performance Metrics and Reporting

## Professional Standards

- **Zero Bloat:** Built entirely on NumPy, Pandas, SciPy, Matplotlib, Seaborn, and OpenCV-headless. 
- **From Scratch:** All machine learning algorithms are mathematically derived and implemented from scratch using NumPy arrays.
- **Cross-Platform:** Extensively tested across Python 3.8 to 3.12 on both Linux and Windows environments.
